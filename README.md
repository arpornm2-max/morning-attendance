# โปรแกรมเช็คชื่อนักเรียนเข้าแถวตอนเช้า (Morning Assembly Attendance)

เว็บแอปพลิเคชันสำหรับเช็คชื่อนักเรียนเข้าแถวตอนเช้า ใช้งานได้ทันทีบนมือถือและคอมพิวเตอร์ ผ่าน **GitHub Pages** โดยไม่ต้องตั้งค่าเซิร์ฟเวอร์หรือฐานข้อมูล (บันทึกข้อมูลอัตโนมัติในเบราว์เซอร์)

## คุณสมบัติหลัก
- **รองรับครบทั้ง 6 สถานะ**:
  - ✅ **มาเรียน**
  - ⏰ **สาย**
  - ❌ **ขาด**
  - 📝 **ลากิจ**
  - 🤒 **ลาป่วย**
  - 🎯 **กิจกรรม**
- **เช็คชื่อได้รวดเร็ว**: มีปุ่ม **"มาเรียนทั้งหมด"** ในคลิกเดียว แล้วค่อยกดปรับสถานะเฉพาะนักเรียนที่สาย/ขาด/ลา/กิจกรรม พร้อมช่องเพิ่ม **หมายเหตุ** รายคน
- **คัดลอกข้อความสรุปส่ง LINE**: จัดรูปแบบข้อความพร้อมวันที่ พ.ศ. ยอดรวมแยกสถานะ และรายชื่อเพิ่มเติม กดปุ่มคัดลอกหรือกดส่งเข้า LINE ได้ทันที
- **บันทึกเป็นรูปภาพสรุปประจำวัน (.png)**: สร้างภาพสรุปความคมชัดสูงด้วย HTML5 Canvas เลือกได้ทั้ง **แบบสรุปกระชับ** และ **แบบแสดงรายชื่อครบทุกคน** พร้อมปุ่มดาวน์โหลดและปุ่มแชร์รูปภาพบนมือถือ
- **จัดการรายชื่อและหลายห้องเรียน**: เพิ่มห้องเรียนได้หลายห้อง วางรายชื่อนักเรียนทีละหลายคนจาก Excel/LINE ได้เลย มีประวัติย้อนหลัง และสำรอง/กู้คืนข้อมูลเป็นไฟล์ `.json`

## วิธีนำขึ้นใช้งานบน GitHub Pages

### วิธีที่ 1: อัปโหลดขึ้น GitHub ผ่านคำสั่ง Git
1. สร้าง Repository ใหม่บน [GitHub](https://github.com/new) (เช่น ตั้งชื่อว่า `morning-attendance` และเลือกเป็น **Public**)
2. เชื่อมต่อและส่งโค้ดขึ้น GitHub:
   ```bash
   git remote add origin https://github.com/<ชื่อผู้ใช้ของคุณ>/morning-attendance.git
   git branch -M main
   git push -u origin main
   ```
3. ไปที่หน้า Repository บน GitHub → คลิกแท็บ **Settings** → เมนู **Pages** (ด้านซ้าย)
4. ตรงหัวข้อ **Build and deployment** → **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1-2 นาที เว็บแอปจะพร้อมใช้งานที่:
   `https://<ชื่อผู้ใช้ของคุณ>.github.io/morning-attendance/`

### วิธีที่ 2: เปิดบนมือถือเหมือนแอป (Add to Home Screen)
เมื่อเปิดลิงก์ GitHub Pages บนมือถือ (Safari / Chrome) สามารถกด **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)** เพื่อเปิดเช็คชื่อเข้าแถวตอนเช้าได้สะดวกเหมือนแอปพลิเคชัน
